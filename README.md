# Car Purchase Prediction

This project involves creating a linear regression model to predict the amount a customer would spend on purchasing a car. The dataset includes various features such as customer demographics and financial information.

## Dataset

The dataset contains the following columns:

- `customer_name`: Name of the customer
- `customer_email`: Email address of the customer
- `country`: Country of residence
- `gender`: Gender of the customer
- `age`: Age of the customer
- `annual_salary`: Annual salary of the customer
- `credit_card_debt`: Credit card debt of the customer
- `net_worth`: Net worth of the customer
- `car_purchase_amount`: Amount spent on car purchase (target variable)

## Objective

The objective of this project is to build a linear regression model that can accurately predict the `car_purchase_amount` based on the other features in the dataset.

## Getting Started

### Prerequisites

- Python 3.x
- Libraries: pandas, numpy, scikit-learn, matplotlib

### Installation

1. Clone the repository from GitHub.
2. Navigate to the project directory.
3. Install the required libraries using a package manager.

## Usage

1. Load the dataset into a pandas DataFrame.
2. Preprocess the data and split it into training and testing sets.
3. Train the linear regression model using the training data.
4. Make predictions with the model and evaluate its performance using appropriate metrics.

## Results

The model's performance can be evaluated using metrics such as Mean Squared Error (MSE) to determine its accuracy in predicting car purchase amounts.
